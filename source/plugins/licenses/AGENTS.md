# licenses

## Purpose
Repository licenses plugin: reports a repository's own license along with the permissions, limitations and conditions
it grants, and - when the Ruby `licensed` gem is available - clones the repository, runs a user-supplied setup command,
enumerates dependency licenses and computes an open-source license ratio bar. `supports: repository` only,
`scopes: public_access`, `category: github`, `index: 6`. `metadata.yml` warns twice: the output is not legal advice, and
the plugin **must not be enabled on web instances because it allows raw command injection** through
`plugin_licenses_setup`.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Fetches the repository's `licenseInfo`, `url` and `databaseId`, then the full GitHub license catalog. Gated on `imports.which("licensed")`: if present it clones `repository.url` into `os.tmpdir()/<databaseId>` with `imports.git`, runs `setup` via `imports.run(setup, {cwd: path}, {prefixed: false})`, writes a minimal `.licensed.yml` (`cache_path: .licensed`) unless one already exists, runs `licensed list --format=json --licenses`, tallies dependency licenses into `used` / `known` / `unknown`, then removes the temp dir. Afterwards it merges the base license's permissions/limitations/conditions with those inherited from dependency licenses, drops base permissions that conflict with an inherited limitation, and builds the stacked ratio `list` with cumulative `x` offsets. |
| `index.mjs` `colors()` | Local helper that classifies every catalog license into a color and sort `order`: `other` (`#8b949e`, 0), strongly protective plus network-use (`#388bfd`, 1), strongly protective (`#79c0ff`, 2), weakly protective (`#7ee787`, 3), permissive (`#56d364`, 4), unknown (`#6e7681`, -1). Classification reads the license's `conditions` / `permissions` keys, not its name. |

## Skipped subdirectories
- `queries/` - no AGENTS.md: `setup.mjs` loads every file there as a GraphQL query string. Contents:
  - `licenses.graphql` (op `LicensesDefault`, no variables) - the global `licenses` catalog: `spdxId`, `name`, `nickname`, `key`, and `limitations` / `conditions` / `permissions`, each `{key, label}`. Reachable as `queries.licenses()` because the file name matches the plugin name.
  - `repository.graphql` (op `LicensesRepository`, vars: `$account`, `$owner`, `$name`) - `licenseInfo {spdxId, name, nickname, key}`, `url` and `databaseId`. `$account` substitutes the **root field name** itself (`user` or `organization`), not an argument.

## For AI Agents
### Working In This Directory
- **External binary requirement.** The whole dependency analysis is behind `if (await imports.which("licensed"))`. The gem
  is installed in the action image (`Dockerfile`: `gem install licensed`), so locally the plugin silently produces only
  the base license section. Install the gem before debugging a "no dependencies found" report.
- `plugin_licenses_setup` is passed verbatim to a shell. That is the documented reason the plugin is unsafe on web
  instances and why it carries the `metrics.run.user.cmd` extra. Do not relax that gate.
- `index.mjs` destructures the repository query result as `const {user: {repository}} = ...` while the query root field is
  substituted from `$account`. An organization-owned repository would return an `organization` root and break this
  destructure. If you touch this code path, test with an org-owned repo.
- `text` is a flat key-to-label map built by flattening every catalog license's properties, so a label collision between
  two licenses silently wins by last-write. Keys come from GitHub, e.g. `disclose-source`, `same-license`,
  `same-license--library`, `network-use-disclose`, `private-use`, `commercial-use`, `modifications`, `distribution`.
- The temp directory is `os.tmpdir()/<repository.databaseId>` and is removed both before cloning and after the run, so
  two concurrent renders of the same repository would collide.
- Licenses not present in the GitHub catalog fall back to a title-cased key, color `#6e7681` and `order: -1`, and are
  counted in `result.unknown`.

### Testing Requirements
- `npx jest --runInBand metrics.test.js -t Licenses` runs `tests/cases/licenses.plugin.yml`. Only one case is generated
  and it is action-mode-only with a 30-minute timeout because it really runs `npm ci` inside a clone.
- Mocks: `tests/mocks/api/github/graphql/licenses.default.mjs` and `licenses.repository.mjs`. The `licensed` invocation
  itself is not mocked; it is skipped when the binary is absent.
- Template rendering it: `source/templates/repository/partials/licenses.ejs` only (not in `classic`).

### Common Patterns
- `imports.which` / `imports.run` / `imports.git` / `imports.fs` / `imports.os` / `imports.paths` all come from
  `source/app/metrics/utils.mjs`; the plugin never imports node builtins directly.
- Sets are used to deduplicate permission/limitation/condition keys before the base-versus-inherited diff.
- Standard enable guard and `try {} catch (error) { throw imports.format.error(error) }`.
