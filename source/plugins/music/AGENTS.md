# music

## Purpose
Renders a user's music activity: random tracks scraped from a playlist page, recently played tracks, or
top played tracks/artists. Four providers (Apple Music, Spotify, Last.fm, YouTube Music) are crossed with
three modes (`playlist`, `recent`, `top`), and not every pair is implemented. `playlist` mode scrapes the
provider's embed page with puppeteer; `recent` and `top` call provider REST APIs through `imports.axios`.
No GitHub data is used at all, so `scopes` is empty and the example workflows pass `token: NOT_NEEDED`.

## For AI Agents
### Working In This Directory
- Provider/mode support is enforced only by `default:` branches that throw. Currently implemented:
  `playlist` for apple/spotify/youtube, `recent` for spotify/lastfm/youtube, `top` for spotify/lastfm.
  Last.fm can never reach `playlist` mode because its embed regex is `/^\b$/`, which matches nothing.
- Mode auto-guessing happens before validation: no `mode` plus a `playlist` value picks `playlist` and
  infers the provider from the URL regexes; otherwise the presence of `music.top.type` or `music.time.range`
  in the query picks `top`; otherwise `recent`.
- Token formats differ per provider and are parsed inline: Spotify wants `"client_id, client_secret, refresh_token"`
  split on commas, Last.fm wants a bare `api_key` interpolated into the URL, YouTube Music wants a raw
  `Cookie` header string containing `SAPISID=`. Apple Music takes no token.
- `sandbox` is a plugin setting, not a user input. The web instance sets it (`source/app/web/instance.mjs`),
  and only then may a caller override the server-side token through `plugin_music_token`.
- Errors are thrown as `{error: {message}, ...raw}` so the partial still renders the provider and mode
  headings. Keep that shape when adding new failure paths.
- `top` mode mutates the module-level `modes` object via `Object.defineProperty(modes, "top", {get})` to
  build the heading text. That is shared state in a long-running web instance, so treat it as a known wart
  rather than a pattern to copy.
- Spotify `top` rejects `limit > 50`; the generic `limit` clamp is `Math.max(1, Math.min(100, limit))`.
- Spotify `recent` has no server-side range parameter, so it walks `after=` timestamps from 0.5 h to 24 h
  back, de-duplicating by track name and breaking early once `limit` is reached.
- Artworks are fetched last and converted with `imports.imgb64`; Spotify playlist scraping has no per-track
  artwork so it falls back to the playlist cover read from a `--image-src` CSS variable.

### Testing Requirements
- `tests/cases/music.plugin.yml` (generated from `examples.yml`) drives the jest run. `npm run test-metrics`.
- Mocks: `tests/mocks/api/axios/post/spotify.mjs` (token exchange, only answers for
  `MOCKED_CLIENT_ID, MOCKED_CLIENT_SECRET, MOCKED_REFRESH_TOKEN`, returns `MOCKED_TOKEN_ACCESS`),
  `tests/mocks/api/axios/get/spotify.mjs` (recently-played, top tracks, top artists; every branch requires
  `Authorization: Bearer MOCKED_TOKEN_ACCESS`), `tests/mocks/api/axios/get/lastfm.mjs`,
  `tests/mocks/api/axios/post/youtubemusic.mjs`.
- `playlist` mode is not mocked at any level. Those test cases really launch puppeteer and really load
  the Apple/Spotify/YouTube embed pages, so they are slow and break when a provider changes its DOM.
- Rendered by `source/templates/classic/partials/music.ejs` only.

### Common Patterns
- Standard plugin guard, input load and `imports.format.error(error)` wrapper as described in the repo root
  conventions.
- Scraping pattern: `imports.puppeteer.launch()`, `page.setUserAgent(...)` with a pinned Chrome 96 UA string,
  `page.goto(playlist)`, `frame.evaluate(...)` returning plain objects, then `browser.close()`.
- Apple Music needs `document.querySelector("embed-root").shadowRoot` plus a hard 10 second sleep because
  its lazy loading defeats `networkIdle`. YouTube Music scrolls until `yt-next-continuation` empties.

## Dependencies
### Internal
`imports.metadata.plugins.music` (enabled/inputs/extras), `imports.puppeteer`, `imports.axios`,
`imports.url.URLSearchParams`, `imports.shuffle`, `imports.imgb64`, `imports.format.date`,
`imports.format.error`, `imports.util.inspect`.
### External
Node `crypto` (imported directly, for the YouTube Music `SAPISIDHASH` sha1). APIs: `accounts.spotify.com/api/token`,
`api.spotify.com/v1/me/player/recently-played`, `api.spotify.com/v1/me/top/{tracks,artists}`,
`ws.audioscrobbler.com/2.0/` (`user.getrecenttracks`, `user.gettopartists`, `user.gettoptracks`),
`music.youtube.com/youtubei/v1/browse` (hardcoded web key and `clientVersion: 1.20211129.00.01`,
`browseId: FEmusic_history`), plus the Apple/Spotify/YouTube embed pages loaded in puppeteer.
