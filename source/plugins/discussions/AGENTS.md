# discussions

## Purpose
GitHub Discussions plugin: counts discussions a user started, comments they wrote and how many of those
comments were marked as answers, then aggregates upvotes and the user's favorite discussion category.
Rendered by the `classic` template only. `supports: user` (no organization/repository mode), `scopes: public_access`,
`category: github`, `index: 15`.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Runs three GraphQL calls: one for totals, then two cursor-paginated loops (100 nodes/page) over started discussions and over discussion comments. Sums `upvoteCount` into `upvotes.discussions` / `upvotes.comments`, tallies `"<emoji> <name>"` per category via `imports.emoji.get(emoji)`, sorts them descending into `categories.stats` and picks `categories.favorite`. |
| `metadata.yml` | Declares `plugin_discussions`, `plugin_discussions_categories` (boolean, default `yes`), `plugin_discussions_categories_limit` (number, default `0` = `zero: disable`, becomes `Infinity` in `display.categories.limit`). |
| `examples.yml` | Single example (`metrics.plugin.discussions.svg`) with `plugin_discussions_categories_limit: 8`. Built into `tests/cases/discussions.plugin.yml`. |
| `README.md` | Generated by `npm run build`. Do not hand-edit. |

## Skipped subdirectories
- `queries/` - no AGENTS.md: `setup.mjs` `load.plugin` reads every file in `queries/` as a GraphQL query string, so a
  `.md` file would be registered as `queries.discussions["AGENTS.md"]`. Contents:
  - `statistics.graphql` (op `DiscussionsStatistics`, vars: `$login`) - three `totalCount` aliases: `started` (`repositoryDiscussions`), `comments` (`repositoryDiscussionComments`), `answers` (`repositoryDiscussionComments(onlyAnswers: true)`).
  - `categories.graphql` (vars: `$login`, `$after`) - `repositoryDiscussions(first: 100, orderBy: {field: CREATED_AT, direction: DESC})`, returning `edges.cursor`, `nodes.upvoteCount` and `nodes.category {emoji, name}`.
  - `comments.graphql` (vars: `$login`, `$after`) - `repositoryDiscussionComments(first: 100)`, returning `edges.cursor` and `nodes.upvoteCount`.

## For AI Agents
### Working In This Directory
- `$after` is a **whole GraphQL argument fragment**, not just a cursor: `index.mjs` passes `after: "<cursor>"` or an
  empty string, which is substituted textually before the `first: 100`. Keep the leading space/comma layout intact when
  editing the `.graphql` files or pagination silently breaks.
- Both pagination loops take the cursor from the **last edge** (`edges[edges.length - 1].cursor`) and stop when a page
  returns zero nodes or no cursor. There is no page cap, so a very active account issues many requests.
- Debug lines here use the prefix `metrics/compute/${login}/discussions > ...`, missing the `plugins >` segment used by
  every other plugin in this repo. Match the surrounding code if you edit, but be aware it deviates from the convention.
- Adding an option means editing `metadata.yml` and then running `npm run build` to regenerate `README.md`, `action.yml`,
  `settings.example.json` and `tests/cases/discussions.plugin.yml`.

### Testing Requirements

- Mocks: `tests/mocks/api/github/graphql/discussions.statistics.mjs`, `discussions.categories.mjs`,
  `discussions.comments.mjs`. Mock filenames map to the **GraphQL operation name** (dots removed, camel-cased), so a

### Common Patterns
- Standard plugin guard: `if ((!q.discussions) || (!imports.metadata.plugins.discussions.enabled(enabled, {extras}))) return null`.
- Totals are flattened with `Object.fromEntries(Object.entries(...).map(([key, value]) => [key, value.totalCount]))`.
- Everything is wrapped in `try {} catch (error) { throw imports.format.error(error) }`.
