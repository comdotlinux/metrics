# sponsors

## Purpose
The `sponsors` plugin (`💕 GitHub Sponsors`, category `github`, index 13) renders a GitHub Sponsors
profile: the sponsors listing introduction text, the currently active sponsors goal with its completion
percentage, and the sponsors avatar wall. It supports `user`, `organization` and `repository` and needs
`read:user` + `read:org`. Optionally it also merges in past (cancelled) sponsorships, which requires a
token belonging to the target account because sponsors activity is private data.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Reads `size`, `sections`, `past`, `title`; runs `queries.sponsors.description()` then paginates `queries.sponsors.active()` (and `queries.sponsors.all()` when `past`), base64-encodes avatars with `imports.imgb64`, replaces avatars of `PRIVATE` sponsors with a hardcoded anonymous PNG data URI, computes `count.{total,active,past}.{count,user,organization}` and sorts `list` by private, then past, then monthly amount. Drops the `goal` section automatically when `activeGoal` is null. |
| `metadata.yml` | Inputs `plugin_sponsors`, `plugin_sponsors_sections` (`goal`, `about`, `list`; default `goal, list, about`), `plugin_sponsors_past` (boolean, documented as not respecting sponsor privacy), `plugin_sponsors_size` (8-64, default 24), `plugin_sponsors_title` (default `Sponsor Me!`). |
| `examples.yml` | Two examples: `metrics.plugin.sponsors.svg` (goal + list + past, personal token) and `metrics.plugin.sponsors.full.svg` (full introduction, token with scopes). |
| `README.md` | Generated by `npm run build` from `metadata.yml` + `examples.yml`. Never hand-edit. |

## Skipped subdirectories
- `queries/` — no AGENTS.md: `setup.mjs` `load.plugin` reads every file in it as a GraphQL query string.
  Contents:
  - `description.graphql` (`query SponsorsDescription`) — `$account(login: "$login") { sponsorsListing { fullDescription, activeGoal { percentComplete, title, description } } }`. Variables: `$account`, `$login`.
  - `active.graphql` (`query SponsorsActive`) — paginated `sponsorshipsAsMaintainer($after first: 100)` returning `edges.cursor` plus `privacyLevel`, `sponsorEntity` (User or Organization fragment with `login`, `avatarUrl(size: $size)`, `url`) and `tier.monthlyPriceInDollars`. Variables: `$account`, `$login`, `$after`, `$size`.
  - `all.graphql` (`query SponsorsAll`) — paginated `sponsorsActivities($after first: 100, period: ALL)` returning `edges.cursor` plus `sponsor` (User/Organization fragment) and `sponsorsTier.monthlyPriceInDollars`. Used only for past sponsorships. Variables: `$account`, `$login`, `$after`, `$size`.

## For AI Agents
### Working In This Directory
- `$after` is injected textually as the whole string `after: "<cursor>"` or `""`; do not turn it into a real GraphQL variable without updating `index.mjs`.
- `$size` is passed as `Math.round(size * 1.5)`, so the requested avatar pixel size is deliberately larger than the display size.
- `size` reaches `avatarUrl(size: $size)` directly; keep the `min`/`max` bounds in `metadata.yml` in sync if you change it.
- `plugin_sponsors_past` needs a token owned by the target `user`; the plugin does not check this and the GraphQL call simply returns nothing useful otherwise.
- Private sponsors are anonymized by overwriting `user.avatar` with an inline base64 PNG placeholder, but `user.login` is still present in the returned data. `past` sponsors are never marked private.
- `source/plugins/sponsors/index.mjs` is listed in `.github/actions/spelling/excludes.txt` (the huge base64 placeholder would otherwise fail the spell-check workflow). If you move or rename that file, update that excludes entry.
- Changing `metadata.yml` requires `npm run build` to regenerate `README.md`, `action.yml`, `settings.example.json` and `tests/cases/sponsors.plugin.yml`.

### Testing Requirements
- Test case: `tests/cases/sponsors.plugin.yml` (generated from `examples.yml`).
- Mocks: `tests/mocks/api/github/graphql/sponsors.description.mjs`, `sponsors.active.mjs`, `sponsors.all.mjs`. `tests/mocks/index.mjs` matches a mock file name to a query by camel-casing it, so `sponsors.active.mjs` backs `query SponsorsActive`. Renaming a `.graphql` query name breaks the mock silently.
- Commands: `npm run test-metrics`, or a mocked single run with `INPUT_USE_MOCKED_DATA=yes INPUT_TOKEN=MOCKED_TOKEN INPUT_DRYRUN=yes`.

### Common Patterns
- Cursor pagination loop: request, take `edges.at(-1).cursor`, repeat `while ((pushed) && (cursor))`.
- Avatar loading is parallelized with `await Promise.all(list.map(async user => user.avatar = await imports.imgb64(user.avatarUrl)))`.
- Markdown fields go through `imports.markdown(text, {mode: "multiline"})` for the listing description.
