# habits

## Purpose
Coding-habits plugin: derives "when and how this account codes" from the GitHub events feed rather than from GraphQL.
It loads up to 1000 recent events, keeps `PushEvent`s within a day window, fetches each commit patch over REST, and from
that computes the most active hour of day, most active day of week, indentation style (tabs vs spaces), average
characters per line of code, and optionally charts plus a recently-used-languages pie. `supports: user, organization`,
`scopes: public_access`, `category: github`, `index: 7`. There is **no `queries/` directory** here; everything is REST.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Pages `rest.activity.listEventsForAuthenticatedUser({username, per_page: 100, page})` for `ceil(from / 100)` pages, filters to `PushEvent` authored by the login (bypassed for organizations), applies `imports.filters.repo(repo, skipped)` and the `days` age cut. Fetches each commit via `rest.request(commit)` under `Promise.allSettled`, keeps only `+` lines of each file patch, then computes `commits.hours`/`commits.days` histograms (shifted by `data.config.timezone.offset`), `indents`, `lines.average.chars`, and builds up to three charts with `imports.Graph.line` / `imports.Graph.pie`. |
| `metadata.yml` | `plugin_habits`, `_from` (events to load, default 200, 1-1000), `_skipped` (inherits `repositories_skipped`), `_days` (default 14, 1-30), `_facts` (default yes), `_charts` (default no; extras `metrics.api.github.overuse`, `metrics.run.tempdir`, `metrics.run.git`), `_charts_type` (`classic`/`graph`/`chartist`, extras `metrics.npm.optional.d3`), `_trim`, `_languages_limit` (8, 0-8), `_languages_threshold` (`"0%"`). |
| `examples.yml` | Two examples ("Mildly interesting facts" and "Recent activity charts"), both pinned to `config_timezone: Europe/Paris`. |
| `README.md` | Generated by `npm run build`. Do not hand-edit. |

## For AI Agents
### Working In This Directory
- This plugin **imports another plugin's code**: `import {recent as recent_analyzer} from "./../languages/analyzers.mjs"`.
  The source comments call this out as a legacy exception to the "plugins do not use other plugins" rule. Changes to
  `source/plugins/languages/analyzer/recent.mjs` therefore affect the habits language pie.
- `recent_analyzer` is called with `{days, load: from || 1000, tempdir: "habits"}`. `tempdir` is not a parameter of
  `recent()` and is ignored; `timeout` is not passed either, so the analyzer runs with no global time limit here.
- `charts_type: chartist` is deprecated and behaves exactly like `graph`; both go through the same
  `["graph", "chartist"].includes(_charts)` branch and require the `metrics.npm.optional.d3` extra.
- Indent detection relies on string coercion of a match array: the code runs `patch.match(/((?:\t)|(?:[ ]{2})) /gm)`
  and then `/^\t/.test(indent)` on the **array**. It works because arrays stringify to their joined elements, but it is
  fragile. Do not "simplify" it without re-checking the tabs/spaces counts.
- `languages.threshold` is a percentage **string** (`"0%"`); it is stripped and divided by 100 before use.
- The timezone offset comes from `data.config.timezone?.offset ?? 0` and is added in milliseconds before reading
  `getHours()` / `getDay()`, so wrong-looking peak hours usually mean a missing `config_timezone`.

### Testing Requirements
- `npx jest --runInBand metrics.test.js -t habits` runs `tests/cases/habits.plugin.yml` (two cases, both `verify: yes`).
- Mocks: `tests/mocks/api/github/rest/activity/listEventsForAuthenticatedUser.mjs` for the events feed and
  `tests/mocks/api/github/rest/request.mjs` for the per-commit patch fetch (it matches
  `https://api.github.com/repos/lowlighter/metrics/commits/MOCKED_SHA`). There is no GraphQL mock for this plugin.
- Template rendering it: `source/templates/classic/partials/habits.ejs` only.

### Common Patterns
- `Promise.allSettled(...)` followed by `.filter(({status}) => status === "fulfilled").map(({value}) => value)` so a
  single unreachable commit does not fail the plugin.
- `empty(n)` helper seeds histograms with zeroes so charts keep full 24-hour / 7-day axes.
- Standard enable guard and `try {} catch (error) { throw imports.format.error(error) }`.
