# languages

## Purpose
Languages activity plugin: reports which languages an account uses. It has three independent data paths that can be
combined in one render - the cheap default (byte sizes from `repository.languages.edges`, already present in the base
query data), a `recently-used` section driven by the REST events feed, and an opt-in `indepth` mode that actually clones
repositories and runs `linguist-js` per commit to count lines and bytes the account personally wrote.
`supports: user, organization, repository`, `scopes: public_access`, `category: github`, `index: 1`.
There is **no `queries/` directory**: the default path reuses base-query data, the other two use REST plus local `git`.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Resolves the 18 inputs, applies `colorsets.json` presets, aggregates `repository.languages.edges` byte sizes into `languages.stats`, optionally calls the recent and indepth analyzers, applies `aliases` (language renaming and grouping), then formats both the `favorites` and `recent` sections: filter by `ignored`, sort desc, slice to `limit`, drop entries under `threshold`, optionally fold the remainder into an `Other` entry, and compute each entry's normalized `value` and stacked `x` offset. |
| `analyzers.mjs` | Thin facade: `indepth()` and `recent()` construct `IndepthAnalyzer` / `RecentAnalyzer` from `analyzer/` and call `.run()`. Also the CLI entry point - it checks `/languages.analyzers.mjs$/.test(process.argv[1])` and, when matched, awaits `cli()` and exits. Wired as `npm run indepth` (`node source/plugins/languages/analyzers.mjs`). |
| `colorsets.json` | Two named palettes, `rainbow` and `complementary`, each an array of 8 `"<index>:<hex>"` entries consumed by `plugin_languages_colors`. |
| `metadata.yml` | 18 inputs: enable, `ignored`, `skipped`, `limit` (0-8), `threshold`, `other`, `colors`, `aliases`, `sections`, `details`, `indepth`, `indepth_custom`, `analysis_timeout`, `analysis_timeout_repositories`, `categories`, `recent_categories`, `recent_load` (100-1000), `recent_days` (0-365). |
| `examples.yml` | Four examples: most-used, most-used with details, recently-used, and indepth (`test: skip: true`, so the indepth case is generated but never executed by jest). |
| `README.md` | Generated by `npm run build` (the largest plugin README in the repo). Do not hand-edit. |

## For AI Agents
### Working In This Directory
- **Three modes, one option gate.** `recently-used` and `indepth` both check
  `imports.metadata.plugins.languages.extras("indepth", {extras})`, so on a web instance both need
  `metrics.cpu.overuse`, `metrics.run.tempdir` and `metrics.run.git` enabled. Errors from either analyzer are caught and
  only logged, so a failing analyzer silently degrades to the default byte-size stats.
- **Colorsets only apply at `limit <= 8`.** The lookup into `colorsets.json` is guarded by a `limit <= 8` check,
  because each palette only defines indices 0-7. Colors are then parsed as `name:color` or `index:color` pairs; a
  per-index color is only used when no per-name color exists for that language.
- **`indepth.custom`** (`plugin_languages_indepth_custom`) takes strings appended to the repository list, in the forms
  `owner/repo`, `owner/repo@branch` or `owner/repo@branch:commits` (a `git rev-list` range), or a full URL for
  non-github.com hosts. `IndepthAnalyzer.ignore()` bypasses `skipped` for anything passed this way.
- **Categories** (`data`, `markup`, `programming`, `prose`, default `markup, programming`) are linguist language *types*;
  the analyzer drops any language whose `cache.languages[lang].type` is not in the list. `recent.categories` defaults to
  `categories` when unset.
- **Timeouts** are in minutes: `analysis.timeout` (global, default 15, max 60) resolves the analyzer promise early and
  sets `results.partial.global`; `analysis.timeout.repositories` (default 7.5, max 15, `zero: disable`) breaks out of a
  single repository's commit loop and sets `results.partial.repositories`. Partial results are still rendered.
- **`lines` detail and the `Other` bucket** only exist in indepth mode - `details` is filtered to drop `lines` when
  `indepth` is off, and `Other`'s line count comes from `missed.lines` via a getter with a no-op setter.
- The repository-mode debug line correctly says `... > languages > switched to repository mode`; the `people`
  copy-paste of that line exists in `introduction` and `lines`, not here.

### Testing Requirements
- `npx jest --runInBand metrics.test.js -t Languages` runs `tests/cases/languages.plugin.yml` (three executed cases;
  the indepth one is skipped).
- Mocks: no GraphQL mock. The recent analyzer is backed by
  `tests/mocks/api/github/rest/activity/listEventsForAuthenticatedUser.mjs` and `.../activity/listRepoEvents.mjs`, commit
  patches by `tests/mocks/api/github/rest/request.mjs`, repository lookups by `.../repos/get.mjs`, and indepth GPG key
  fetching by `.../users/listGpgKeysForUser.mjs`.
- Templates rendering it: `source/templates/classic/partials/languages.ejs`,
  `source/templates/repository/partials/languages.ejs`, `source/templates/terminal/partials/languages.ejs`.
- Manual analyzer run without the full engine:
  `npm run indepth -- --login=<user> --token=<token> lowlighter/metrics` (add `--mode=recent` for the recent analyzer).

### Common Patterns
- `colorsets.json` is read at runtime with `imports.fs.readFile` relative to `imports.__module(import.meta.url)`, not
  imported, so it can be edited without a rebuild.
- Alias folding mutates the stats objects in place (`delete stats[language]` then add into `stats[alias]`), which is why
  the loop iterates over a snapshot list of four stat objects.
- Standard enable guard and `try {} catch (error) { throw imports.format.error(error) }`.

## Dependencies
### Internal
- `./analyzer/*` via `analyzers.mjs`, `source/app/metrics/utils.mjs` (`fs`, `filters`, `format`, `__module`),
  `source/app/metrics/metadata.mjs`, `source/app/metrics/setup.mjs` (imported by `analyzer/cli.mjs`),
  `data.user.repositories.nodes`, `data.user.repositoriesContributedTo.nodes` and `data.shared["repositories.skipped"]`
  from the base query.
- Consumed by `source/plugins/habits/index.mjs`, which imports `recent` from `analyzers.mjs`.
### External
- `linguist-js` (language detection), `simple-git` (cloning), `@octokit/rest` and `yargs-parser` (CLI only), plus the
  system `git` and `gpg` binaries in indepth mode.
