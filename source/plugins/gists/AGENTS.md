# gists

## Purpose
Gists plugin: paginates through every gist owned by the account and sums stargazers, forks, files and comments across
the non-forked ones. Forked gists are counted in `totalCount` (which comes straight from the API) but excluded from the
aggregates. `supports: user`, `scopes: public_access`, `category: github`, `index: 24`. Smallest plugin in this batch:
one query, one option, no extras.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Cursor-paginated loop (100 gists/page, `orderBy UPDATED_AT DESC`) collecting nodes into a `gists` array, then a single pass that `continue`s on `gist.isFork` and accumulates `stargazerCount`, `forks.totalCount`, `comments.totalCount` and `files.length`. Returns `{totalCount, stargazers, forks, files, comments}`. |

## For AI Agents
### Working In This Directory
- The file is `gists.graphql` but the **operation** is `GistsDefault`; because the file name matches the plugin name it is
  reachable as `queries.gists({login, after})` rather than `queries.gists.gists(...)`.
- `$after` substitutes a full argument fragment (`after: "<cursor>"` or empty string), not a bare cursor value.
- `gists.totalCount` is assigned onto the array itself (`gists.totalCount = totalCount`) each page, so it reflects the API
  total including forks, while `stargazers`/`forks`/`files`/`comments` exclude forks. Keep that distinction if you touch
  the partial.
- `files` counts files across all non-forked gists, not gists; `files.name` is requested purely to get `length`.
