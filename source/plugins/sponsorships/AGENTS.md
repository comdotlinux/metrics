# sponsorships

## Purpose
The `sponsorships` plugin (`💝 GitHub Sponsorships`, category `github`, index 12) is the mirror image of
the `sponsors` plugin: instead of who sponsors you, it shows who *you* sponsor. It reports the lifetime
amount spent through GitHub Sponsors, the date of the first sponsorship, and the list of sponsored
accounts with their tier names. Supports `user` and `organization`; scopes `read:user` and `read:org`.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Reads `sections` and `size`. For the `amount` section it runs `queries.sponsorships()` and converts `totalSponsorshipAmountAsSponsorInCents / 100`, sets `image` to the GitHub `hearts_around` emoji asset (base64-encoded through `imports.imgb64`) and `started` to the oldest sponsorship `createdAt`. For the `sponsorships` section it paginates `queries.sponsorships.all()` and maps each node to `{login, avatarUrl, type, tier, private, past}` where `private` is `privacyLevel !== "PUBLIC"` and `past` is `!isActive`. |
| `metadata.yml` | Inputs `plugin_sponsorships`, `plugin_sponsorships_sections` (`amount`, `sponsorships`; both on by default), `plugin_sponsorships_size` (8-64, default 24). |
| `examples.yml` | One example producing `metrics.plugin.sponsorships.svg` with a personal token. |
| `README.md` | Generated by `npm run build` from `metadata.yml` + `examples.yml`. Never hand-edit. |

## Skipped subdirectories
- `queries/` — no AGENTS.md: `setup.mjs` `load.plugin` reads every file in it as a GraphQL query string.
  Contents:
  - `sponsorships.graphql` (`query SponsorshipsDefault`) — the plugin's default query, reached as `queries.sponsorships(...)`. Fetches `totalSponsorshipAmountAsSponsorInCents` plus `sponsorshipsAsSponsor(first: 1, activeOnly: false, orderBy: {field: CREATED_AT, direction: ASC})` to get the very first `createdAt`. Variables: `$account`, `$login`.
  - `all.graphql` (`query SponsorshipsAll`) — paginated `sponsorshipsAsSponsor($after first: 100, activeOnly: false, orderBy: {field: CREATED_AT, direction: DESC})` returning `edges.cursor` plus `createdAt`, `isActive`, `isOneTimePayment`, `tier.name`, `privacyLevel` and `sponsorable` (User or Organization fragment with `login`, `avatarUrl(size: $size)`, `url`). Variables: `$account`, `$login`, `$after`, `$size`.

## For AI Agents
### Working In This Directory
- The file named after the plugin (`queries/sponsorships.graphql`) is the one callable as `queries.sponsorships()`; every other file is `queries.sponsorships.<basename>()`. That naming convention comes from `setup.mjs`, not from this directory.
- `$after` is a textual placeholder that receives the literal string `after: "<cursor>"`, and `$size` receives `Math.round(size * 1.5)`.
- `isOneTimePayment` is selected by `all.graphql` but never read in `index.mjs`; it is available if you want to distinguish one-time from recurring sponsorships.
- When `sections` does not include `amount`, `amount` stays `NaN` and `started` stays `null`; templates must tolerate that.
- Any `metadata.yml` change needs `npm run build` to regenerate `README.md`, `action.yml`, `settings.example.json` and `tests/cases/sponsorships.plugin.yml`.

### Testing Requirements
- Test case: `tests/cases/sponsorships.plugin.yml`.
- Mocks: `tests/mocks/api/github/graphql/sponsorships.default.mjs` (backs `query SponsorshipsDefault`) and `sponsorships.all.mjs` (backs `query SponsorshipsAll`). The mock file name is camel-cased by `tests/mocks/index.mjs` to match the `query <Name>` header, so renaming a query breaks the mock.
- Commands: `npm run test-metrics`, or `INPUT_USE_MOCKED_DATA=yes INPUT_TOKEN=MOCKED_TOKEN INPUT_DRYRUN=yes` for a single mocked run.

### Common Patterns
- Standard pagination `do { ... } while ((pushed) && (cursor))` loop with `edges.at(-1).cursor`.
- Destructuring the account key out of the GraphQL response: `const {[account]: {sponsorshipsAsSponsor: {edges, nodes}}} = await graphql(...)`.
- Avatars base64-encoded in parallel via `Promise.all` + `imports.imgb64`.
