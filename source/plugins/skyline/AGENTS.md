# skyline

## Purpose
Captures an animated turntable of a 3D contributions calendar by loading an external WebGL page in puppeteer
and recording a fixed number of frames. The default target is `skyline.github.com`, but the whole page
contract (URL, readiness condition, settle delay, elements to hide) is exposed as one JSON input, so the same
plugin drives alternative sites such as honzaap's GitHub City. Output is either an embedded GIF or a
CSS-animated frame sequence, and both make the rendered SVG very large.

## Key Files
| File | Description |
|------|-------------|
| `index.mjs` | Resolves year and viewport, loads the `settings` JSON (falling back to the metadata default when the extras gate is not granted), drives puppeteer through goto/waitForFunction/sleep/hide, then calls `imports.record` or `imports.gif` and returns `{animation, width, height, compatibility}`. |
| `metadata.yml` | `category: github`, `index: 27`, `supports: user` only, `scopes: []`. Inputs: `year` (min 2008, defaults to the current year), `frames` (1-120, default 60; 120 is a full loop and 60 a half loop), `quality` (0.1-1, default 0.5), `compatibility`, `settings` (JSON). Plugin extras: `metrics.cpu.overuse`, `metrics.npm.optional.gifencoder`, `metrics.run.puppeteer.scrapping`. The `settings` input additionally needs `metrics.run.puppeteer.user.js`. |
| `examples.yml` | Two examples (GitHub Skyline, GitHub City). Both carry `test.skip: true` with `modes: [action]` and a 1800000 ms timeout, and both carry `prod.skip: true` with the comment "Currently skyline always return 404". |
| `README.md` | Generated by `npm run build`. Do not hand-edit. |

## For AI Agents
### Working In This Directory
- `settings` is the security-sensitive input. `ready` is a JavaScript expression handed to
  `page.waitForFunction`, and `hide` is a CSS selector evaluated in the page, so arbitrary user JavaScript
  runs in the browser. That is exactly why it sits behind the `metrics.run.puppeteer.user.js` extra, and why
  a denied extra falls back to `JSON.parse(imports.metadata.plugins.skyline.inputs.settings.default)` rather
  than to the user value. Do not relax that gate.
- `${login}` and `${year}` are templated into both `url` and `ready` with `replaceAll`, so a custom site can
  receive them as query parameters or match on them in the readiness expression.
- Viewport is `454 * (1 + data.large)` wide by `284` tall. `data.large` is set by the core plugin from
  `config_display: large` (`source/plugins/core/index.mjs`), so the capture doubles in width for large output.
- Both `page.goto` and `page.waitForFunction` use a 90 second timeout, and `wait` adds a further fixed sleep
  in seconds after readiness. A slow WebGL site can therefore take minutes per render.
- `compatibility` picks the encoder: `imports.record({page, width, height, frames, scale: quality})` produces
  separately encoded frames driven by CSS animation, which works in Firefox and Safari but multiplies file
  size; otherwise `imports.gif({page, width, height, frames, quality: Math.max(1, quality * 20)})` embeds a
  GIF. Note the two functions interpret `quality` differently, one as a scale factor and one as a GIF
  quantizer setting. Both live in `source/app/metrics/utils.mjs`.
- `year` falls back to the current year when the parsed input is `NaN`, which is how `default: current-year`
  in the metadata is actually implemented.
- The browser is closed after encoding but not in a `finally`, so a failure mid-capture leaks the puppeteer
  process. Worth fixing if you touch this file.

### Testing Requirements
- `tests/cases/skyline.plugin.yml` exists but is literally `[]`, because both examples set `test.skip: true`.
  Nothing exercises this plugin in CI, so changes here need a manual run.
- There are no mocks of any kind. `tests/mocks/index.mjs` mocks graphql, rest, axios, rss-parser and Google
  Maps, none of which this plugin uses. Any run really launches Chromium and really loads the target site.
- Manual mocked run of the action, from the repository root:
  `INPUT_USE_MOCKED_DATA=yes INPUT_TOKEN=MOCKED_TOKEN INPUT_DRYRUN=yes INPUT_PLUGIN_SKYLINE=yes node source/app/action/index.mjs`.
  Expect it to be slow, and expect the default `skyline.github.com` URL to fail, per the `prod.skip` comment.
- Rendered by `source/templates/classic/partials/skyline.ejs` only.

### Common Patterns
- Puppeteer capture lifecycle shared with the `music` playlist mode and the community `screenshot` plugin:
  `imports.puppeteer.launch()`, `page.setViewport`, `page.goto`, wait for a condition, `frame.evaluate` to
  clean up the DOM, capture, `browser.close()`.
- A JSON-typed input used as a small declarative scraping contract rather than as several string inputs.

## Dependencies
### Internal
`imports.metadata.plugins.skyline` (enabled/inputs/extras, and `inputs.settings.default` read directly),
`imports.puppeteer`, `imports.record` and `imports.gif` from `source/app/metrics/utils.mjs`,
`imports.format.error`, `data.large` from `source/plugins/core/index.mjs`.
### External
Chromium via puppeteer, the optional `gifencoder` npm package (hence the
`metrics.npm.optional.gifencoder` extra), and the third-party site being captured
(`skyline.github.com` by default).
